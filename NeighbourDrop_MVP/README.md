# NeighbourDrop MVP — Case Study 97

A lightweight prototype for the Go-to-Market & Customer Operations final examination.

## Core case assumptions
- Membership: ₹149/month
- Expected members: 600
- Expected deliveries/member/month: 5
- Service radius: 3 km
- Expected deliveries/month: 3,000
- Monthly membership revenue at 600 members: ₹89,400

## Demo flow
Membership → Store selection → Order concept → Delivery

## How to run
Open `index.html` in a browser. No installation or server is required.

## Exam purpose
This is a prototype/MVP demonstration of the proposed customer journey. It is not intended to represent a production-ready delivery platform.
